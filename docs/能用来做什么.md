# 这个项目能用来做什么

一次**实测**的结果，不是功能列表。跑 `python tools/what_it_does.py` 可以自己复现（18 项检查，0 失败）。

---

## 一句话

**它是一个「不骗人的量化研究台」** —— 拉真实行情、算指标、跑回测、模拟下单，
并且**把每个结论的计算过程都摊开给你看**。

适合：想验证一个策略想法、想看懂指标怎么算的、想有个能真实记录模拟持仓的地方。

不适合：想赚钱。**它跑不赢买入持有**（下面有实测数据）。

## 二、能算 27 个指标

500 根 **27ms**。每个指标的口径都用**可手算的小数组**核对过：

```
贵州茅台 1d 最新一根：
  close 1329.0    ema12 1283.05   ema26 1279.70
  rsi 65.37       macd_dif 3.35   adx 19.96
  atr 22.27       bb_upper 1313.30  bb_lower 1221.74
  kdj_k 96.56     volume_ma20 2884495
```

**口径要点**（这些地方错了不会报错，只会数字悄悄偏）：
Wilder 平滑 α=1/n、种子取前 n 个**有效值**、布林带用总体标准差 ddof=0（不是 pandas 默认的 ddof=1）、
MACD 柱 = (DIF−DEA)×2（国内习惯的双倍）。

## 四、能回测（含成本，且对比买入持有）

**贵州茅台 1d / 500 根 / 初始 100 万 / 手续费 0.03% + 滑点 0.05%：**

| 策略 | 收益 | 买入持有 | 超额 | 回撤 | 夏普 | 交易 | 胜率 |
|---|---|---|---|---|---|---|---|
| 双均线趋势 | −21.50% | +5.26% | **−26.75%** | 22.93% | −1.50 | 7 | 0.0% |
| RSI 均值回归 | +3.85% | +5.26% | **−1.41%** | 13.12% | −0.01 | 1 | 100% |
| 布林带突破 | −7.96% | +5.26% | **−13.22%** | 11.70% | −0.55 | 8 | 25.0% |
| MACD 趋势 | +3.40% | +5.26% | **−1.85%** | 31.82% | −0.01 | 21 | 28.6% |
| 唐奇安突破 | −3.05% | +5.26% | **−8.31%** | 12.12% | −0.33 | 5 | 40.0% |

### ★ 跑赢买入持有的策略：0 / 5

**这恰恰是这个项目最有价值的地方** —— 它不给你「年化 300%」的漂亮回测，
而是老实告诉你这 5 个教科书策略在真实数据上**一个都没跑赢躺着不动**。

很多回测工具会把这个结果藏起来，或者默认不加成本、允许用未来数据，
让每个策略看起来都能赚钱。这个不会：

- **强制 shift 一根，且不提供关闭开关** —— 信号在第 i 根收盘产生，第 i+1 根**开盘**成交。
  我手算核对过：从第 100 根买入持有的手算值是 −10.15%，回测给 −9.59%，
  差异正是来自「按下一根开盘成交」而非当根收盘。
- **成本必须建模** —— 上面 RSI 策略的成本拖累 0.25 个百分点。
- **坏数据会警告而不是静默算错**。

## 五、能搜参数（但结果要打折看）

24 组参数 **1.06 秒**。输出同时给样本内 / 样本外 / 全样本：

```
最优组合 fast=5 slow=20 adx_min=0
  样本内  −12.90%   回撤 17.54%   7 笔
  样本外   −7.58%   回撤  7.74%   3 笔
  全样本  −25.21%   回撤 29.20%  12 笔
  成本拖累 1.45 个百分点
```

⚠️ **没有 walk-forward 验证**，搜出来的「最优」就是样本内最优，会高估。这是已知局限。

## 六、能模拟盘（真实约束）

- **T+1**：按成交日判断，不是自然日
- **涨跌停校验**、**手数取整**（A 股 100 股整数倍）
- 手续费 + 滑点 + 最低佣金
- 止损 / 止盈 / 移动止损 / 回撤熔断 / 冷却期
- **账户持久化**，跨请求保持

两种下单模式，且**都记在成交记录里**：
- `next_open`（默认）：等下一根开盘成交，**无未来函数**
- `market`：立即按当前价成交，**有同一根内的前视**（界面上写明了）

---

## 七、能接 AI 做决策（默认 DeepSeek）

4 个供应商：`deepseek`（默认）/ `openai` / `ollama` / `custom`。
页面上直接配，**密钥只存本机 `quant/state/`（已在 .gitignore），不回显给浏览器**。

**但要说清楚**：AI 的输出只是**建议**，风控层独立生效 —— AI 说「清仓」也能突破最大仓位限制，
说「不变」也会被风控强制平仓。而且**真实模型下的决策质量我没法验证**（没有可用的 API key）。

---

## 八、能看决策过程（决策驾驶舱）

这是这个项目**最独特**的部分。跑通后能一眼看到：

```
状态：震荡市（ADX 19.96）→ 权重偏向均值回归
  趋势      +0.100 × 0.50 =  +0.050
  动能      +0.100 × 0.40 =  +0.040
  强度      +0.000 × 0.30 =  +0.000
  超买超卖   -0.769 × 1.80 =  -1.384   ← 权重最大，主导决策
  通道位置   -1.000 × 1.20 =  -1.200
  量能      +0.670 × 0.40 =  +0.268
分数 -0.4839 → 动作 hold
```

**为什么这比一张条形图有用**：`强度` 的裸值（0.81）常是最大的，
但 `趋势` 的**贡献**可能更大 —— 因为它权重高。只看值会误判谁在主导决策。

还有最值得看的那一帧：**风控拦截** —— 因子说买、信号说卖、
实际因为止损强制卖，三件矛盾的事同屏可见。

## 九、能让 Agent 驱动蜘蛛（MCP）

`mcp/` 是完整的本地 stdio MCP 服务（依赖已装）。
Agent 创建会话 → 拿预览地址 → 按真实进度上报 → 浏览器实时展示蜘蛛抓词、弧形飞行、三路分流。

用途：**把 Agent 的执行过程变成看得见的东西**，而不是盯着滚动的日志。

## 它**不**能做什么

- **不能下真实单** —— 全是模拟盘，不接券商
- **不能做空 / 加杠杆 / 衍生品** —— 只有做多和空仓
- **不是投资建议** —— 见上面那张表最后一行
- **不能作为服务暴露** —— 两个服务都没有鉴权，默认只绑 127.0.0.1
- **Docker / Makefile 没验证过** —— 本机没有对应工具，写好了但没跑过

**如果你想要一个「会告诉你策略其实没用」的回测工具** —— 这个就是。
