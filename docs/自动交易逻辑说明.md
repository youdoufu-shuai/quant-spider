# 自动交易逻辑说明

> 在 http://127.0.0.1:4400/paper.html 的「自动交易」卡片里配置。
> 核心实现在 `quant/autotrader.py`。

---

## 为什么重写了原来的逻辑

原来的自动交易是两行代码：**策略信号 → 全仓买 / 全平卖**。问题：

| # | 问题 | 后果 |
|---|---|---|
| 1 | 只有 0/1 两种仓位 | 全仓进出。一次误判就打满，没有回旋余地 |
| 2 | **没有风控** | 亏多少都扛着。没有止损、止盈、移动止损、回撤保护 |
| 3 | 单因子决策 | 只看一个策略。均线金叉时 RSI 可能已超买、MACD 可能是负的 |
| 4 | 决策不可解释 | 日志只有「策略转多」四个字 |
| 5 | 每根全量重算 | 300 根 K 线每次刷新重算 27 个指标 |

---

## 新的三层结构

```
┌─ 第 1 层：信号 ────────────────────────────────────────┐
│  四种模式：多因子打分 / 多策略共识 / 单策略 / 外部 AI    │
│  产出：目标仓位比例（0.0 ~ 1.0），不是 0/1               │
└───────────────────────────────────────────────────────┘
┌─ 第 2 层：仓位 ────────────────────────────────────────┐
│  三种方式：固定比例 / 随信心变化 / 按波动率              │
│  分档阈值：目标与当前差 < 阈值就不动（省手续费）          │
└───────────────────────────────────────────────────────┘
┌─ 第 3 层：风控 ────────────────────────────────────────┐
│  止损 / 止盈 / 移动止损 / 回撤熔断 / 冷却期 / 最短持有    │
│  ★ 风控优先于信号 —— 触发就执行，不看分数               │
└───────────────────────────────────────────────────────┘
```

所有成交都走**下一根开盘价**，与回测口径一致，**没有未来函数**。

## 多因子打分模型（默认模式）

6 个因子，每个输出 -1 ~ +1，加权求和归一化：

| 因子 | 含义 | 怎么算 |
|---|---|---|
| 趋势 | EMA12 与 EMA26 的差 | `(ema12-ema26) / (1.5×ATR)` |
| 动能 | MACD 线（DIF）方向 | `macd_dif / (1.5×ATR)` |
| 强度 | ADX 定强弱 + DI 定方向 | `(adx-20)/20` 倍方向 |
| 超买超卖 | RSI 反向 | `(50-rsi) / 20` |
| 通道位置 | 布林带 %B 反向 | `1 - 2×%B` |
| 量能 | 量比 × 趋势方向 | `(量比-1)×2` 倍方向 |

### ★ 权重随市场状态自适应（这是最关键的设计）

**不能给所有因子固定权重。** 第一版就是这么写的，自检立刻打脸 —— 单边下跌时出现：

```
trend -1.00   strength -1.00            ← 明确看空
reversion +1.00  position +0.79  momentum +0.83   ← 明确看多
总分 +0.03 → 判定观望，完全不作为
```

**两个根因**：

1. `reversion`（超卖）和 `position`（布林位置）**是同一个概念的两次计数** ——
   价格一路跌，RSI 必然低、%B 必然低，两项同时给出"看多"，双倍抵消趋势信号
2. **均值回归只在震荡市成立**。单边趋势里"超卖"可以一直超卖，拿它抄底是亏钱的主要方式

**修法**：用 ADX 判定市场状态，两套权重：

| 因子 | 趋势市（ADX≥25） | 震荡市（ADX≤20） |
|---|---|---|
| 趋势 | **1.8** | 0.5 |
| 强度 | **1.5** | 0.3 |
| 动能 | 1.2 | 0.4 |
| 超买超卖 | **0.15** | **1.8** |
| 通道位置 | 0.5 | 1.2 |
| 量能 | 0.5 | 0.4 |

ADX 在 20~25 之间时线性插值过渡。

**修复后的实测结果**：

| 市场 | 趋势 | 动能 | 强度 | 总分 | 决策 |
|---|---|---|---|---|---|
| 单边上涨 1.2%/根 | +1.00 | +1.00 | +1.00 | **+0.694** | **买入 95%** |
| 单边下跌 1.2%/根 | -1.00 | -1.00 | -1.00 | **-0.700** | 空仓 |
| 温和上涨 0.5%/根 | +1.00 | +1.00 | +1.00 | +0.696 | 买入 95% |
| 震荡市 | -0.09 | -0.09 | -0.02 | **+0.089** | 观望 |

判据：总分 ≥ 开仓阈值（默认 0.25）就买，≤ 平仓阈值（-0.25）就卖，中间观望。

### 另外两个设计要点

**① 方向量用 ATR 归一化，不用绝对百分比。**
最初写 `EMA差 / 价格 / 0.02`（偏离 2% 满分）。自检打脸：每天涨 1.2% 的序列 EMA 只差 1.2%，达不到 2% 的线，总分算出 +0.00 —— 明显该买却不买。绝对百分比对不同波动率的标的不通用（加密一天动 5%、指数动 0.5%），除以 ATR 后自动适配。

**② 动能因子用 MACD 线，不用 MACD 柱。**
柱 = DIF - DEA，衡量"加速度"。指数衰减序列里它**必然是正的** —— 越跌基数越小，跌幅绝对值在缩小，短期均线反而比长期均线"跌得少"，柱转正。一个正在崩盘的标的会显示"动能看多 +0.83"把看空信号抵消掉。DIF 才是纯方向量。

## 仓位管理

| 方式 | 说明 |
|---|---|
| **固定比例**（默认） | 每次都用固定比例，默认 95% |
| **随信心变化** | 打分越高仓位越重：`0.30 + 0.70 × 归一化信心` |
| **按波动率** | `目标波动率 / (ATR/价格)`，波动大就轻仓 |

**分档阈值**（默认 15%）：目标与当前差小于阈值就不下单。
省手续费，也避免信号在阈值附近抖动时反复买卖 —— 那是真实账户被磨死的主要原因之一。

## 风控（优先于信号）

| 规则 | 默认 | 说明 |
|---|---|---|
| 止损 | 6% | 从持仓成本跌 6% 卖出 |
| 止盈 | 20% | 从持仓成本涨 20% 卖出 |
| 移动止损 | 8% | 从持仓最高价回撤 8% 卖出（仅浮盈时生效） |
| 回撤熔断 | 25% | 账户回撤达线 → 清仓 + 停手，只允许离场 |
| 冷却期 | 3 根 | 卖出后 3 根内不开仓，避免被反复打脸 |
| 最短持有 | 0 根 | 买入后至少持有几根才允许卖 |

**检查顺序很重要**：止损 → 止盈 → 移动止损 → 熔断 → 冷却 → 信号。
先触发哪个就执行哪个。比如浮盈 100% 时会先触发止盈（20%），轮不到移动止损 —— 这是**正确**的，不是 bug。

所有参数在界面上「风控参数」里可改，留空 = 关闭该项。

## 四种模式对照

| 模式 | 怎么决策 | 适合 |
|---|---|---|
| **多因子打分** | 6 因子加权 + 状态自适应 | 默认推荐，信号质量最好 |
| **多策略共识** | 5 个策略投票，≥N 个同向才动手 | 更保守，信号更少更滞后 |
| **单策略** | 只用选定的一个策略 | 与最早版本一致，可用来对照 |
| **外部 AI** | 交给模型判断 | 见下节 |

界面上有「**试算一次决策**」按钮 —— **不改行情、不下单**，先看它会怎么判断。
这是主要使用方式：先看清楚逻辑，再决定要不要开启。

## 关于「内置一个 AI 自己买卖」

我实现了 **AIDecider**，但**没有内置调用模型**，原因：

- 这台机器上**没有可直接调用的模型 CLI**
- `~/.dsh/.credentials.yaml` 存的是用户凭据 —— 拿它去直连模型既不可靠（不知道端点与配额）也不合适（等于绕过 harness 自己发请求）

所以做成**可插拔**。三种接法任选：

```powershell
# 1) 任何 OpenAI 兼容端点（Ollama / vLLM / LM Studio / 官方 API）
$env:QTRADER_AI_URL   = "http://127.0.0.1:11434/v1/chat/completions"
$env:QTRADER_AI_MODEL = "qwen2.5:14b"
$env:QTRADER_AI_KEY   = "sk-xxx"          # 本地模型可留空

# 2) 任意命令行程序：stdin 收 JSON，stdout 回 JSON
$env:QTRADER_AI_CMD = "python my_agent.py"

# 3) 任意 HTTP 服务：POST JSON，回 JSON
$env:QTRADER_AI_URL = "http://127.0.0.1:8000/decide"
```

然后在界面上把模式选「外部 AI 决策」。

**AI 收到什么**：20 项指标的数值（带含义说明）+ 账户状态 + 最近成交。
刻意只给结构化数值、不给原始 K 线数组 —— 体积小、省 token，
而且关键指标预先算好，避免模型自己做算术（它算不准）。

**AI 要回什么**：
```json
{"action": "buy|sell|hold", "target": 0.0~1.0, "reason": "一句话理由"}
```

### 安全设计：AI 的输出只是「建议」

| 保护 | 作用 |
|---|---|
| 风控在本地判定 | 止损/止盈/熔断**不问 AI**，直接执行 |
| `target` 夹到 `[0, max_fraction]` | AI 说"满仓"也突破不了上限 |
| 非法动作降级为 hold | AI 返回乱码不会误下单 |
| 调用失败自动兜底 | 回落内置打分逻辑，**风控不会因为网络问题停摆** |

**一个胡说的模型不能把账户打爆。** 这几条都在自检里验证过。

## 本轮修掉的真 bug

| # | 问题 | 症状 | 怎么发现的 |
|---|---|---|---|
| 1 | `getattr(ind, "ema12")` 取不到值 | 指标在 `ind.values` **字典**里，不在属性上 → 所有因子算不出来、总分恒为 0 | 自检「冷却期过后可开仓」失败 |
| 2 | 绝对百分比归一化 | 温和上涨算不出看多 | 同上 |
| 3 | 固定权重 | 单边下跌被均值回归因子抵消成"观望" | 打分诊断 |
| 4 | MACD 柱当动能 | 崩盘时显示"动能看多" | 打分诊断 |
| 5 | `meta=` 无条件传给 `AutoDecider` | `TypeError` 被 except 吞掉 → **自动交易开了但永不下单** | 自检「上涨行情发出买入委托」失败 |
| 6 | 试算被 `if not self.auto` 挡住 | 关闭状态下无法预览决策 | API 测试 |
| 7 | 全角括号/逗号混进代码 | `SyntaxError: '(' was never closed` | 语法检查 |

前 5 个**不报错**，只是让结果悄悄错掉或功能静默失效 —— 这正是自检的价值。

## 已知限制

1. **只能做多** —— 没有做空
2. **没有参数优化** —— 阈值和权重是手工设的，没跑网格搜索
3. **单标的** —— 一个账户一个标的，没有组合层面配置
4. **AI 模式未实测** —— 本机没有可用模型端点，只验证了接口、兜底与夹紧逻辑
5. **分档阈值会漏掉小机会** —— 差 15% 以内不动，可能错过连续小幅调仓的收益
