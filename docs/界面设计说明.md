# 界面设计说明

![看板](screenshots/quant-board.png)

这一版界面重做过两次。第一次叫「行情底稿」——去掉了卡片、统一了字体，
但**骨子里还是工具**：信息密度高、字号小、按功能分区。
第二次（现在这版）叫**「私人银行月报」**：一张深色硬封面，翻开是安静的白色报表。

---

## 一、方向：为什么是「月报」不是「杂志」

想找「高级简约」的参照时，最容易滑向**编辑式 / 杂志风**：
米白底 + 高对比衬线 + 发丝线 + 零圆角 + 密排小字。

它看起来有文化，但问题是**没有材质、没有重量，而且和任何主题都无关** ——
同一套东西套在做咖啡的、做数据的、做工具的网站上都成立。
这恰好也是当下 AI 生成页面最常见的套路之一。

真正的奢侈感来自两件事：**材质对比** 和 **克制的量**。
所以这版用了一个更具体的比喻：**装在信封里的一份对账单**。

> 一张深色硬封面，上面压着产品名、导航、页面名；
> 翻开是白纸报表，留白很足，只有数字在对齐。

---

## 二、唯一的胆量：封面

整站只有**一个**地方允许张扬：页首那块全出血的深墨蓝封面。

```
┌────────────────────────────────────────────────────────┐
│  量化工作台   看板 云图 选股 决策驾驶舱 …    ● 就绪      │  ← 象牙小字
│                                                        │
│                                                        │
│  看 板                    自选标的的实时行情、           │  ← 宋体 68px
│                                     技术指标与回测。     │  ← 象牙灰
└────────────────────────────────────────────────────────┘
   （以下是纯白报表，留白 72px，什么都不抢）
```

封面之下**没有第二个深色块、没有强调色、没有图标**。
按 Chanel 的说法：出门前照镜子，摘掉一件配饰。

---

## 三、颜色：三个决定

| 角色 | 值 | 为什么 |
|---|---|---|
| 封面 | `#16202b` 深墨蓝 | 钢笔水的颜色。不是纯黑（纯黑像开发者工具），不是藏青（太企业） |
| 封面文字 | `#f3f0e9` 象牙 | 全站**唯一**的暖色，只出现在封面上 —— 这点暖是「材质」，不是配色 |
| 报表 | `#ffffff` 白 | 不铺灰底、不铺卡片。封面和白纸的对比就是边界 |
| 正文墨 | `#171a1e` | 近黑，带一点点冷 |
| 涨 / 跌 | `#a02a24` 酒红 / `#2e6152` 松绿 | **全站唯一的彩色**，因为它们是数据，不是装饰 |

**没有品牌色。** 奢侈品牌不需要一个「主题色」，它需要材质。
所以链接、焦点、按钮、选中态全部用墨色 —— 不引入第三种颜色。

涨跌用的是降饱和的酒红和松绿，而不是股市常见的荧光红绿：
`#d92b3f` / `#12a06a` 那种亮度在白色报表上会「跳」，破坏安静。

---

## 四、字体：宋体只在展示层

```
展示层（≥30px）：STSong / 宋体  —— 封面页名、大数字、报价、指标读数
正文与界面：      系统无衬线     —— 标签、表格、说明、按钮
```

**为什么宋体只用在大字上**：宋体在 14px 以下会糊，横画会断。
把它限制在 30px 以上，它给的是「刻意的庄重」；用在正文里就成了「假装有文化」。

这也是财报和杂志的通行做法：**标题有性格，正文守规矩**。

Latin 数字全部开 `tabular-nums`（等宽数字），右对齐时小数点才对得齐。

---

## 五、图表：烤蓝钢

K 线图的指标线原来是默认图表库的配色（蓝 `#2563eb`、紫 `#7c3aed`、金 `#b8860b`、粉 `#d6336c`），
放在这套系统里像一块补丁。

改成了**烤蓝钢**（blued steel）—— 奢侈腕表指针的经典工艺：

| 用途 | 色值 |
|---|---|
| 快线（EMA12 / DIF / K） | `#5a6e85` 浅烤蓝 |
| 慢线（EMA26 / DEA / D） | `#2f4054` 深烤蓝 |
| 辅助（SMA20 / BOLL 中轨） | `#8e9aa8` 褪色钢 |
| 布林带 | `#c3c8cd` 极浅 |

这不是随便挑一个蓝色：**它有一个真实材质出处**。
K 线仍然是酒红 / 松绿，指标线全是钢色 —— 彩色只留给价格。

## 六、规避的套路

设计说明里写清楚「刻意不做什么」，比写「做了什么」更有用：

| 套路 | 为什么不用 |
|---|---|
| 奶油底 + 高对比衬线 + 陶土色 | 最常见的「AI 想做高级」 |
| 近黑底 + 荧光绿 / 朱红 | 第二常见 |
| 报纸式：满屏发丝线 + 密排小字 + 竖线分栏 | 第三常见，且和主题无关（这一版的第一稿就是它，被自己否掉了） |
| 统一圆角卡片 + 同一阴影 | SaaS 后台观感 |
| 金色渐变 / 金属质感 / 发光 | 假装贵，其实廉价 |
| 全大写 eyebrow 标签 | 模板化外壳 |
| 中点「·」连接元信息 | 同上（这一版把站内所有 `·` 都去掉了） |
| 每个区块 fade-in 入场 | 分散注意力，不传递信息 |

## 七、结构编码了什么

只有**真正携带信息**的结构才留下：

| 结构 | 编码的信息 |
|---|---|
| 封面深色块 | 「这是一页的开头」 |
| 表格横向行线 | 行与行的边界（没有竖线，因为列已经右对齐） |
| 输入框的 3px 圆角 | 「这个东西可以操作」，和纸面数据区分 |
| `.sess.cur::before` 的小竖条 | 当前选中的账户 |
| 涨跌色 | 方向（唯一允许用颜色的地方） |

反过来，这些**不编码信息**的装饰都删了：分区横线、区块编号、图表网格加强、
卡片阴影、图标、徽章、进度条渐变。

## 八、已知的取舍

1. **封面占掉约 250px 高度**。信息密度让位于节奏感 —— 这是个每天看的工具，
   多点呼吸比多两行数据重要。窄屏会自动压缩到 200px 左右。
2. **宋体在非 Windows 上可能退化**（没装 STSong 时 fallback 到 SimSun 或系统衬线），
   封面页名的气质会打折扣。这是不引入网络字体的代价（项目原则：零网络依赖）。
3. **深色封面在强光下对比度**：象牙 `#f3f0e9` 对墨蓝 `#16202b` 的对比度约 13:1，
   远超 WCAG AA。
4. **模拟盘的账户读数**是两列网格（`#kv1` / `#kv2`），因为 JS 往里塞的是平铺的
   标签 / 数值对，不是嵌套行 —— 详见 `paper.html` 里的注释，别改回 `.kv` 的横向 flex
   （改回去会让每个汉字单独换行，实测过）。
5. **几张旧截图**（`ai-config.png`、`auto-logic.png`、`screen-portfolio.png`、
   `paper-final.png`、`paper-symbols.png`、`decision-risk.png`）还是上一版的，
   内容仍准确但视觉过时，下次改到对应功能时一并重拍。

## 九、怎么改

改颜色 / 字号 / 间距，只改 `quant/web/theme.css` 顶部的 `:root`。
页面里**不要**写死颜色 —— 除了画布（`chart.js` 的 theme 对象）。

```
quant/web/theme.css            设计系统（颜色、字号、组件）
quant/web/*.html               页面；每页顶部 <style> 只放本页专属尺寸
quant/web/chart.js             画布主题（和 theme.css 对齐）
quant/web/decision-cockpit.js  决策驾驶舱画布主题
quant/web/heatmap.html         云图的色阶（幂曲线饱和）
```
