## 数据源：多源自动降级

本机网络实测（2026-10-16）：

| 数据源 | 延迟 | 状态 |
|---|---|---|
| **Binance 数据镜像** | 245ms | ✅ 稳定（加密主源） |
| **新浪财经** | 122ms | ✅ 稳定（A股主源） |
| **腾讯财经** | 246ms | ✅ 稳定（A股备用） |
| 东方财富 | — | ❌ **被封禁** |

### 为什么必须做降级

东方财富**一开始是好的** —— 首次自检 7/7 全过。随后我压测 10 次，
它开始拒绝连接，最后**整个 IP 被重置**：

```
加完整浏览器头    → RemoteDisconnected (58ms)
加 1.2s 请求间隔  → RemoteDisconnected (69ms)
换 push2 主机     → RemoteDisconnected
```

**这不是限流，是 IP 级封禁**（60ms 内立刻重置，连 TCP 都建不起来）。

★ 教训：单一数据源在生产里一定会出事。所以设计成**链式降级** ——
每个市场配一串来源，逐个尝试，谁先成功用谁，并把实际命中的源显示在页头。

### ⚠️ 一个极易踩的坑：字段顺序不同

```
新浪 : [日期, open, high, low, close, volume]   ← 标准 OHLC 顺序
腾讯 : [日期, open, CLOSE, HIGH, LOW, volume]   ← close 在第二位！
东财 : [时间, open, close, high, low, volume]   ← 也是 close 第二位
```

按腾讯的顺序当标准 OHLC 解析，**high 和 low 会互换**。
后果：所有基于最高/最低价的指标（ATR、唐奇安通道、布林带）
以及回测里的止损止盈判断**全部是错的**，**而且不会报错** —— 只是结果悄悄错掉。

所以三个解析器分开写，并在自检里断言 `h >= c >= l`。

## 指标引擎：实现细节决定对错

| 指标 | 关键点 |
|---|---|
| **RSI** | 必须用 **Wilder 平滑**（α=1/n），不是简单均值。用错会和所有行情软件对不上 |
| **ATR** | 真实波幅要取三者最大：`max(H-L, \|H-前C\|, \|L-前C\|)`。漏掉后两项，跳空缺口统计不到 |
| **布林带** | 用**总体标准差**（ddof=0），这是 Bollinger 本人的定义。pandas 默认 ddof=1，用错带宽偏大 |
| **ADX** | 必须过滤「同向占优」：+DM 与 -DM 只有一个能计入 |
| **KDJ** | D = SMA(K)，而 K 开头天然是 NaN，所以 SMA 必须能容忍窗口内 NaN |
| **所有指标** | 前 n-1 位是 NaN（数据不足），**不做填充** —— 填充会让策略在开头产生假信号 |

## 回测引擎：禁止自欺

### 一、强制禁止未来函数

第 i 根收盘产生的信号，**只能在第 i+1 根开盘成交**。

为什么：策略看到的是收盘价，而收盘那一刻已经无法再以该价格成交。
如果用「第 i 根收盘价」成交，等于假设自己能预知收盘价并刚好在那里成交 ——
**回测收益会被严重高估**。这是量化回测里最常见的自欺方式。

本引擎强制 shift 一根，**且不提供关闭开关**。

### 二、成本必须建模

- A 股：万三手续费 + 万五滑点，且**必须整手（100 股）交易**
- 加密：千一 + 万五

「**成本拖累**」是用**零成本重跑一遍**实测出来的差值，不是估算。
实测：MACD 策略在茅台日线上做了 21 笔，被成本吃掉 **3.62 个百分点**。

### 三、未平仓不计入胜率

期末仍有持仓时，浮动盈亏**不参与**交易统计 —— 否则统计会被虚高。

## 模拟盘：真实约束

| 约束 | 说明 |
|---|---|
| **T+1** | A 股当日买入不能当日卖出。按**成交日**判断（不是信号日） |
| **涨跌停** | 一字涨停买不进、一字跌停卖不出 |
| **整手交易** | A 股 100 股一手。茅台约 1329 元/股，一手就要 13.3 万 |
| **默认资金** | A 股 100 万 / 加密 10 万。给 10 万买茅台会全部被拒（买不起一手） |

### ⚠️ 安全边界

**这是模拟盘，不是实盘。** 本模块：
- 只读行情，不连接任何交易接口
- 不持有任何 API Key，**没有下单能力**
- 不产生任何真实委托

所有成交都在内存里推演。

## 自检抓出的 8 个真实 bug

这些**全部会静默算错**（不报错，只让结果悄悄错掉）：

| # | Bug | 后果 |
|---|---|---|
| 1 | `wilder()` 种子取 `values[:n]` | 前导 NaN → **ADX 整条序列报废** |
| 2 | `sma()` 用 cumsum | 一个 NaN 污染全窗 → **KDJ 的 D 线永远算不出** |
| 3 | RSI 索引错位一格 | **RSI 数值全偏**，末尾恒 NaN |
| 4 | RSI 数组越界 | IndexError 崩溃 |
| 5 | 腾讯 K 线字段顺序 `O,C,H,L` | **high/low 互换**（提前规避） |
| 6 | 成本拖累计算自我递归 | RecursionError |
| 7 | `np.bool_` 不是内置 bool | JSON 序列化失败 |
| 8 | 模拟盘 T+1 用信号日而非成交日 | **T+1 判断偏一天** |

这 8 个里有 6 个不会抛异常，只会让回测结果错掉 ——
**这正是量化最危险的地方**。所以每个都固化成回归断言（`test_indicators.py`）。

## 已知限制

1. **只有做多 + 空仓**，没有做空（`allow_short` 参数存在但未实现）
2. **全仓进出**，没有仓位管理（凯利公式、固定比例、波动率目标都没做）
3. **没有参数优化**，用的是各策略的经典默认参数
4. **单一标的**，没有跨品种对冲或组合
5. **A 股数据源随时可能再被封** —— 已备 3 个源，但如果全挂就得换数据源
6. **前端图表是自写的 Canvas**，没有十字光标、缩放、拖拽等交互
