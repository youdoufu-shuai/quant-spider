# Prompt Spider UI — 本地部署说明

> 原项目：[Kirito14IT/prompt-spider-ui](https://github.com/Kirito14IT/prompt-spider-ui)（MIT · 30★）
> 一个用**原生 JavaScript + Canvas 2D** 做的**提示词可视化界面**。

---

## 立即运行

**双击 `启动.cmd`** —— 它会启动服务器并自动打开浏览器。

或者手动：
```powershell
node server.mjs
# 打开 http://127.0.0.1:4317
```

## 这个项目是什么

一句话：**把 AI Agent 的工作过程，用一只机械蜘蛛抓词 + 蛛网分流的方式可视化出来。**

具体画面流程：

```
文字（提示词）
   ↑
机械蜘蛛沿文字游走
   ↓ 伸出触手
逐词扫描 → 弧形抓取 → 接触驻留 → 收臂
   ↓ 词条飞行
蛛网分流 ──┬──→ code    （规则/确定性处理）
           ├──→ model   （模型处理）
           └──→ you     （需要人工确认）
   ↓
双拍心跳 + 高密度蛛丝 + 粉色扫描线
```

**它的用途**：把"一个 prompt 进去、任务分流到三条路径"这个抽象过程，
变成**看得见的运动**。适合用来展示 Agent 工作流、录屏做演示、或者单纯觉得好看。

**三条分支是可视化概念，不是真实执行**：
`code` 分支不执行生成的代码，`model` / `you` 也不会真的调用模型或请求批准。
导出的 JSON 里保留 `modelCalls: 0` 和 `executedActions: 0` 字段 —— 这个设计很诚实。

## 怎么用（三种玩法）

### ① 看完整动画（零配置）

打开就是**参考演示**，时长 **20.92 秒**，末段显示 175 次分流：`137 code / 27 model / 11 you`。

| 快捷键 | 功能 |
|---|---|
| `Space` | 播放 / 暂停 |
| `R` | 从头重播 |
| `F` | 切换沉浸模式 |
| `Esc` | 退出沉浸模式 / 收起控制栏 |
| `←` `→` | 后退 / 前进 0.5 秒 |

底部控制条有 **0.5× / 1× / 2× / 4×** 速度、循环开关、可拖动的时间轴。

- **点画布里的词条或决策流** → 自动展开右侧控制栏，看问题、示意分数和分支
- **点 `code` / `model` / `you`** → 筛选只看某条分支
- **右上"放大画布" / "全屏"** → 专注画面

### ② 试自己的提示词（零配置）

1. 右侧展开「控制」抽屉
2. 选「**自己的提示词**」
3. 输入中文或英文
4. 点「**扫描提示词**」

它用**本地关键词和规则**生成示意分数：

| 规则 | 去向 |
|---|---|
| 达到阈值的词 | → `code` |
| 低于阈值 | → `model` |
| 命中**发布 / 购买 / 删除**等批准相关词 | → `you`（优先） |

**拖动分流阈值滑块**可以实时看分支变化。点「导出本次分流 JSON」保存当前时间点的状态。

> ⚠️ 分数**未经概率校准**，是 UI 演示用的示意值。

### ③ 接入自己的 Agent（MCP）—— 需要额外配置

这才是这个项目的**核心卖点**：让支持本地 stdio 的 Agent 调用这个 UI，
**实时展示它正在做什么**。

**MCP 工具链**（共 11 个工具）：

```text
spider_create_session   → 创建会话，返回带 token 的预览链接
spider_update_events    → 上报任务步骤（id / label / route / status）
spider_configure_session→ 改标题、模型标签、布局、分支名、配色
spider_control_playback → 暂停 / 跟随实时
spider_complete_session → 结束展示
spider_export_session   → 导出 JSON 回放
spider_export_project   → 导出独立可运行项目
...
```

**调用示例**：
```javascript
spider_create_session({ config: { title: "我的 Agent 工作流", layout: "landscape", unit: "task" } })

spider_update_events({
  sessionId: "SESSION_ID",
  events: [
    { id: "check-1", label: "检查输入格式", route: "code",  status: "completed" },
    { id: "draft-1", label: "生成草稿",     route: "model", status: "running" }
  ]
})

// 用同一个 id 更新状态，不会重复累计
spider_update_events({
  sessionId: "SESSION_ID",
  events: [
    { id: "draft-1",  status: "completed" },
    { id: "review-1", label: "等待人工确认", route: "you", status: "pending" }
  ]
})

spider_complete_session({ sessionId: "SESSION_ID", status: "completed" })
spider_export_project({ sessionId: "SESSION_ID", name: "my-spider-ui", includeReplay: true, includeMcp: true })
```

**注册到 Agent**（以支持 `mcpServers` 的客户端为例）：
```json
{
  "mcpServers": {
    "prompt-spider": {
      "command": "C:/Users/24942/.dsh/dsh-runtimes/dsh-primary-runtime/dependencies/node/bin/node.exe",
      "args": ["C:/Users/24942/Documents/deepseek-harness/default-workspace/prompt-spider-ui/mcp/server.mjs"]
    }
  }
}
```

> 注意：`command` 用 **node 的绝对路径**（本机 node 不在 PATH 里）。
> 选 **stdio / 本地进程**，不要把浏览器预览地址当 MCP 服务地址。

**三种布局**：

| 布局 | 画布尺寸 | 适合 |
|---|---|---|
| `portrait`（默认） | 1080 × 1350 | 竖屏、展示录制 |
| `landscape` | 1600 × 900 | 桌面演示、工作流面板 |
| `square` | 1080 × 1080 | 方形展示、紧凑预览 |

## 部署时遇到的问题与解法

### ① 本机**没有 npm**

自带 Node 是精简发行版 —— 只有 `node.exe`，没有 `npm` / `npx`，
系统里也没装官方 Node.js。所以 README 要求的 `npm --prefix mcp ci` **无法执行**。

### ② registry 极慢，标准安装会挂死

npm registry 单次响应要 **19 秒**；没有超时的下载会无限挂起
（实测卡了一个包 10 分钟）。

### ③ 解法：自己写了个安装器

好在 `package-lock.json` 已经记录了每个包的**精确 resolved URL 和 integrity 哈希**，
所以**不需要任何依赖解析逻辑**：

**`tools/install-from-lock.mjs`** —— 零依赖的极简安装器
1. 读 lock 文件拿到 14 个包的 URL + sha512
2. 下载 tarball（**AbortSignal 超时 + 退避重试 + 并发 6**）
3. **校验 integrity**，不匹配就报错，不静默通过
4. 用内置 `gunzip` + 自写 tar 解析器解压到 `node_modules`

**第一版教训**：没有超时，`@modelcontextprotocol/server` 卡死 10 分钟。
**第二版**加了超时/重试/并发，13/14 成功，但那个包仍然 `fetch failed` ——
奇怪的是**同一个 URL 用 PowerShell 却能秒下**（镜像源 282ms）。
于是加了 `.tarball-cache/` 预下载支持，问题解决。

**结果：14/14 安装成功。**

### ④ 改写 `启动.cmd`

原版是 `node server.mjs`，依赖 node 在 PATH。本机没有，
所以改成写死 `node.exe` 绝对路径，并自动打开浏览器。

## 注意事项

- **服务只监听本机 `127.0.0.1`** —— 外部访问不到，这是设计如此
- **会话默认只存在内存里** —— 退出 Agent / MCP 前请主动导出
- **每个进程最多 20 个会话**，单会话最多 10,000 事件 / 16 MiB 日志
- **导出的独立项目**包含可编辑源码、主题配置、许可证和双语说明，
  进目录 `npm start` 即可运行（需要 npm）
- 输入框聚焦时不会触发播放快捷键
- 系统开启「减少动态效果」时，页面默认暂停并减少部分动画
