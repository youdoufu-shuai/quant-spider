说明与边界

· 数据来源：加密走 Binance 数据镜像；A 股走新浪财经（腾讯备用，东方财富末位）。页头显示实际命中的源。
· 没有未来函数：第 i 根收盘产生的信号，强制在第 i+1 根开盘成交。收益不是「预知收盘价」算出来的。
· 成本已建模：A 股万三手续费 + 万五滑点，且必须整手（100 股）交易；加密千一 + 万五。「成本拖累」是用零成本重跑一遍实测出来的差值，不是估算。
· 模拟盘不是实盘：只读行情，不连接任何交易接口，不持有 API Key，不产生真实委托。所有成交都在内存里推演。
· 未平仓不计入胜率：期末仍有持仓时，浮动盈亏不参与交易统计，避免虚高。
· 策略是公开经典逻辑：双均线（CTA 基本款）、RSI（Wilder 原书）、布林带（Bollinger 顺势用法）、MACD（Appel 原义）、唐奇安（海龟法则）。
