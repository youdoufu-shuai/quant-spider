决策蛛网—

看多 看空 中性 丝的粗细 = 权重 丝上光点 = 贡献值 v×w 蜘蛛径向 = |分数| 蜘蛛朝向 = 动作 顶部张力弧 = 离阈值距离

因子分解—

因子怎么算的值权重 贡献占比方向
权重不是固定的 —— 它随市场状态变。 趋势市里「趋势」权重 1.8、「超买超卖」只有 0.15；震荡市反过来（0.5 / 1.8）。 所以同一组因子值在不同状态下会得出不同结论，这是有意的。
贡献 = 值 × 权重，它才是真正推动分数的量。 实测里经常出现「裸值最大的因子贡献不是最大」——只看值会误判谁在主导决策。

风控闸门—

闸门作用阈值状态
风控优先于信号：触发止损/止盈/移动止损/回撤熔断时强制平仓， 不看打分。蛛网里会看到蜘蛛想冲向决策区却被闸门拦住 —— 那是最值得看的一帧，说明「信号要动，但风控不让」。

决策理由

—

怎么读这张图

1. 量化流程本身就是一张网
6 因子 → 加权 → 分数 → 阈值 → 风控 → 仓位。 蛛网画的就是这条链路，不是"K 线随时间爬"。

2. 每根丝是一个因子
丝的粗细是它的权重（越大越有话语权）， 颜色是方向，光点是贡献值 v×w。 光点越靠外、越亮，这一项对最终决策的推动越大。

3. 蜘蛛的位置是有含义的
径向 = |分数|。趴在中枢附近说明证据不足、立场不明显； 快贴到边缘说明分数很大、立场明确。 朝向永远指向当前动作（BUY 在上 / SELL 在下 / HOLD 在右）。

4. 顶部那道弧是"还差多少"
弧从 0 分画到 1 分，红色刻度是开仓阈值。 弧填满 = 够线该动手；没填满说明还在等。

5. 风控是闸门，不是建议
蜘蛛要冲向决策区，但闸门关着就是过不去。 这时候你会同时看到「信号分数很高」和「实际不动仓」—— 这个矛盾就是风控在起作用，纯文字日志很难一眼看出。

6. 为什么能"重演计算过程"
量化是确定性的：同样的 K 线 + 同样的参数 → 同样的因子与分数。 所以重演不是装饰动画，而是把一次真实计算的分层结果按顺序演一遍。 每次重演都准确复现上面的数字。
